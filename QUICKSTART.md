# 🚀 ШВИДКИЙ СТАРТ - RecordsManager

## ⚡ Миттєва інструкція (5 хвилин)

### Для користувачів:
```
1. Завантажте RecordsManager.exe
2. Запустіть файл (двічі клацніть)
3. Готово! База даних створиться автоматично
```

### Для розробників:
```
1. Отворіть build_exe.py
2. Виконайте: python build_exe.py
3. EXE буде в папці dist/
```

---

## 🔄 ОНОВЛЕННЯ

### Користувачам:
- При запуску програма перевіряє оновлення
- Якщо нове - просто завантажте новий EXE

### Розробникам:
```bash
# Оновить версію
echo "1.0.1" > version.txt

# Скомпілювати
python build_exe.py

# Завантажити на GitHub
git add version.txt
git commit -m "v1.0.1"
git push origin main
```

## ❓ ПРОБЛЕМИ?

### Програма не запускається?
→ Перезавантажте ПК або завантажте ще раз

### Дані не зберігаються?
→ Перевірте файл `records.db` у папці

### Не можу вибрати шаблон?
→ Використовуйте стандартний `template.docx`

### Немає оновлень?
→ Перевірте інтернет з'єднання
