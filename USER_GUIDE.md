# Інструкція для користувачів - RecordsManager

## 🚀 Запуск програми

### Перший запуск:
1. Завантажте файл `RecordsManager.exe` з [Releases](https://github.com/YOUR_USERNAME/YOUR_REPO/releases)
2. Розмістіть файл в папку за вашим вибором
3. Двічі клацніть на файл для запуску
4. При першому запуску програма:
   - Проверить наявність оновлень (можна пропустити)
   - Створить локальну базу даних
   - Ініціалізує всі таблиці

### Подальші запуски:
- Просто запустіть `RecordsManager.exe`
- Програма завантажить всі ваші попередні записи

## 📋 Структура папки програми

Після першого запуску у папці програми з'явиться:
```
📁 Папка з RecordsManager.exe/
├── RecordsManager.exe          (сама програма)
├── version.txt                 (версія додатка)
├── template.docx               (стандартний шаблон)
└── records.db                  (ваша база даних)
```

⚠️ **Важливо**: Не видаляйте `records.db` - це ваша база даних!

## 🗂️ Резервна копія даних

### Як зробити резервну копію:
1. Знайдіть папку з `RecordsManager.exe`
2. Скопіюйте файл `records.db` в безпечне місце
3. Можете скопіювати його на зовнішний накопичувач або у хмару

### Як відновити дані:
1. Якщо щось пішло не так
2. Замініть пошкоджений `records.db` на ваш файл резервної копії
3. Запустіть програму - дані будуть відновлені

## 🎯 Основні операції

### Додавання нового запису:
1. Заповніть форму зліва (обов'язково - лісництво)
2. Натисніть зелену кнопку **"Додати ділянку"**
3. Запис з'явиться в таблиці внизу

### Пошук запису:
1. Введіть текст у поле пошуку
2. Таблиця автоматично фільтруватиметься
3. Натисніть **"Скинути"** щоб показати все

### Редагування запису:
1. Клацніть на рядок у таблиці
2. Дані автоматично завантажиться в форму
3. Змініть те, що вам потрібно
4. Натисніть **"Редагувати вибране"**

### Видалення запису:
1. Виберіть запис у таблиці
2. Натисніть **"Видалити вибране"**
3. Підтвердіть видалення

### Заповнення документа:
1. Виберіть запис у таблиці
2. Натисніть **"Заповнити акт передачі"**
3. Якщо вперше - виберіть шаблон (файл .docx)
4. Виберіть де зберегти документ
5. Готово! Документ автоматично заповнено

## 📁 Вибір шаблону документа

### Перший раз:
- Програма попросить вас вибрати шаблон
- Виберіть файл з розширенням .docx
- Рекомендується використовувати `template.docx` з папки програми

### Створення власного шаблону:
1. Відкрийте стандартний `template.docx` в Microsoft Word
2. Редагуйте документ за вашим бажанням
3. Збережіть як новий файл .docx
4. При заповненні виберіть свій шаблон

### Теги для шаблону:
У шаблоні введіть ці теги там, де мають бути дані:
- `{{lisnyctvo}}` - Лісництво
- `{{kvartal}}` - Квартал
- `{{vydil}}` - Виділ
- `{{ploshcha}}` - Площа
- `{{gospodarstvo}}` - Господарство
- `{{sklad}}` - Склад
- `{{vik}}` - Вік
- `{{povnota}}` - Повнота
- `{{lisorubny}}` - Лісорубний квиток
- `{{data_lisorub}}` - Дата лісорубного квитка
- `{{vyd_korystuv}}` - Вид користування
- `{{sposib_rubki}}` - Спосіб рубки
- `{{rik_rubki}}` - Рік рубки
- `{{rozrad_vysot}}` - Розряд висот
- `{{kilkist_derev}}` - Кількість дерев
- `{{objem_hlysta}}` - Обсяг хлиста

## 🆘 Розв'язання проблем

### Програма не запускається:
- **Рішення 1**: Перезавантажте комп'ютер
- **Рішення 2**: Завантажте програму ще раз
- **Рішення 3**: Перевірте, що у вас Windows 10 або новіше

### Дані не збережені:
- Перевірте, що в папці є файл `records.db`
- Переконайтесь, що диск не переповнений
- Спробуйте скопіювати дані резервної копії

### Не можу вибрати шаблон:
- Шаблон повинен мати розширення **.docx**
- Спробуйте скопіювати шаблон до папки програми

### Документ не заповнювався:
- Переконайтесь, що шаблон містить теги типу `{{field_name}}`
- Перевірте, що всі теги написані правильно
- Спробуйте використовувати стандартний шаблон
