# RecordsManager - Система керування записами про лісосіки

## Описання
RecordsManager - це українська додаток для управління записами про лісосіки, автоматичного заповнення актів передачі на основі шаблонів Word.

## Функціональність

### Основні можливості:
- **Управління записами**: додавання, редагування, видалення записів про ділянки
- **Пошук і фільтрація**: швидкий пошук за різними параметрами
- **Заповнення документів**: автоматичне заповнення актів передачі на основі шаблону
- **База даних**: локальне зберігання даних у SQLite
- **Перевірка оновлень**: автоматична перевірка нових версій при запуску
- **Інтуїтивний інтерфейс**: зелені кнопки та світло-зелене тло

### Поля запису:
- Основні: лісництво, квартал, виділ, площа, господарство
- Лісорубні квитки та дати
- Вид користування та спосіб рубки
- Розрахункові дані: кількість дерев, обсяги деревини
- Заготівельник та реквізити договору

## Установка

### Системні вимоги:
- Windows 10/11 (64-bit)
- 100 МБ вільного місця на диску
- Екран 1024x768 мінімум

### Установка та запуск:
1. Завантажте `RecordsManager.exe` з [Releases](https://github.com/YOUR_USERNAME/YOUR_REPO/releases)
2. Запустіть файл - встановлення не потрібне
3. При першому запуску база даних буде створена автоматично

## Використання

### Додавання запису:
1. Заповніть поля форми
2. Натисніть кнопку "Додати ділянку"
3. Запис з'явиться в таблиці

### Редагування запису:
1. Натисніть на запис у таблиці
2. Дані завантажиться в форму
3. Змініть необхідні поля
4. Натисніть "Редагувати вибране"

### Заповнення документа:
1. Виберіть запис у таблиці
2. Натисніть "Заповнити акт передачі"
3. Виберіть шаблон (якщо вперше)
4. Виберіть місце для збереження
5. Документ буде автоматично заповнено

### Пошук:
1. Введіть текст у поле пошуку
2. Таблиця фільтруватиметься в реальному часі
3. Натисніть "Скинути" для скасування пошуку

## Шаблон документа

Для використання власного шаблону:
1. Створіть документ Word (.docx)
2. У місцях, де мають вставлятися дані, введіть теги виду: `{{назва_поля}}`

### Доступні теги для шаблону:
- `{{lisnyctvo}}` - Лісництво
- `{{kvartal}}` - Квартал
- `{{vydil}}` - Виділ
- `{{ploshcha}}` - Площа
- `{{gospodarstvo}}` - Господарство
- `{{sklad}}` - Склад
- `{{vik}}` - Вік
- `{{povnota}}` - Повнота
- `{{lisorubny}}` - Лісорубний квиток
- `{{data_lisorub}}` - Дата лісорубного квитка
- `{{vyd_korystuv}}` - Вид користування
- `{{sposib_rubki}}` - Спосіб рубки
- `{{rik_rubki}}` - Рік рубки
- `{{rozrad_vysot}}` - Розряд висот
- `{{kilkist_derev}}` - Кількість дерев
- `{{objem_hlysta}}` - Обсяг хлиста
- `{{dilova_hv}}` - Ділова хвойних
- `{{drova_hv}}` - Дров'яна хвойних
- `{{hmyz_hv}}` - Хмиз хвойних
- `{{dilova_tv}}` - Ділова твердолистяних
- `{{drova_tv}}` - Дров'яна твердолистяних
- `{{hmyz_tv}}` - Хмиз твердолистяних
- `{{dilova_ml}}` - Ділова м'яколистяних
- `{{drova_ml}}` - Дров'яна м'яколистяних
- `{{hmyz_ml}}` - Хмиз м'яколистяних
- `{{razom_dilova}}` - Всього ділової
- `{{razom_drova}}` - Всього дров'яної
- `{{razom_hmyz}}` - Всього хмизу
- `{{razom_likvid}}` - Разом ліквіду

## Копіювання та вставлення даних

У програмі підтримуються стандартні буферні операції:
- Скопіювавши дані з Excel, вставте їх у поля форми
- Поля Combobox можна редагувати через буфер обміну

## Резервна копія даних

База даних зберігається в файлі `records.db` у папці програми. Рекомендується регулярно робити резервні копії цього файлу.

## Вирішення проблем

### Програма не запускається:
- Перевірте, що у вас встановлена Windows 10 або новіше
- Спробуйте перезавантажити комп'ютер
- Завантажте програму ще раз

### Дані не зберігаються:
- Перевірте дозволи на запис у папку програми
- Переконайтесь, що диск не переповнений

### Немає можливості вибрати шаблон:
- Переконайтесь, що файл шаблону має розширення .docx
- Спробуйте скопіювати шаблон до папки програми вручну
